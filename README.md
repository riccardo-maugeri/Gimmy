# Gimmy

App personale per seguire la scheda in palestra: serie, carichi, timer di recupero, progressione automatica e storico.
I dati restano salvati sul telefono. Dalla sezione **Scheda** si può salvare un backup.

## Pubblicarla con GitHub Pages (una volta sola)

1. Su github.com: pulsante **+** in alto a destra → **New repository**. Nome: `Gimmy`, visibilità **Public**, poi **Create repository**.
2. Nella pagina del progetto vuoto: link **uploading an existing file**. Trascina tutti i file di questa cartella (i file, non la cartella) e premi **Commit changes**.
3. **Settings** → **Pages** (menu a sinistra). In "Build and deployment": Source **Deploy from a branch**, Branch **main** e cartella **/ (root)**, poi **Save**.
4. Dopo 1-2 minuti, nella stessa pagina compare il link: `https://TUO-NOME-UTENTE.github.io/Gimmy/`.

## Metterla sull'iPhone

1. Apri il link con **Safari**.
2. Tasto **Condividi** → **Aggiungi alla schermata Home**.
3. Da quel momento aprila sempre dall'icona: i dati dell'icona sono separati da quelli di Safari.

## Aggiornamenti

Quando ricevi file nuovi: nel progetto su GitHub **Add file** → **Upload files**, trascina i file e **Commit changes**.
L'app si aggiorna da sola: la nuova versione appare alla seconda apertura.
